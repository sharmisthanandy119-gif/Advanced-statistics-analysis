# Advanced Statistics Analysis Project

## Project Overview

This project demonstrates statistical analysis techniques using Python and Jupyter Notebook.

The project includes:

* One-Way ANOVA
* Two-Way ANOVA
* Exploratory Data Analysis (EDA)
* Principal Component Analysis (PCA)
* Eigenvalues & Eigenvectors
* Feature Scaling
* Correlation Analysis
* Business Insights & Interpretation

---

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* SciPy
* Jupyter Notebook

---

## Key Highlights

### ANOVA Analysis

* Performed one-way ANOVA for Education vs Salary
* Performed one-way ANOVA for Occupation vs Salary
* Conducted two-way ANOVA with interaction effects
* Generated interaction plots

### PCA Analysis

* Performed scaling before PCA
* Extracted eigenvalues and eigenvectors
* Built scree plots
* Calculated cumulative explained variance
* Reduced dimensionality using principal components

### Business Insights

* Education significantly impacts salary
* PCA helps reduce multicollinearity
* Highly correlated features identified through heatmaps
